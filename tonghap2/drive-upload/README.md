# 생애주기 PDF 제출 연결

학생 화면과 한 페이지 PDF 생성은 `tonghap2/life.html`에 있습니다. 이 폴더는 지정한 Google Drive 폴더로 PDF를 받기 위한 서버 코드입니다.

## 연결 방식

`life.html`의 `DRIVE_UPLOAD_URL`로 PDF를 전송하며, 서버에서 저장 성공 응답을 받은 경우에만 완료를 표시합니다. PDF 다운로드도 별도로 사용할 수 있습니다.

## 교사 계정에서 한 번 연결

1. 지정한 폴더 소유자 계정으로 Google Apps Script 프로젝트를 만듭니다.
2. `Code.gs` 내용을 넣고, 프로젝트 설정에서 manifest 표시 후 `appsscript.json`을 적용합니다.
3. 새 배포 → 웹 앱. 실행 사용자: 나, 액세스: 모든 사용자. 학교 계정 정책에 따라 익명 웹 앱이 허용되지 않으면 학교 관리자 확인이 필요합니다.
4. Google이 요구하는 Drive 권한을 교사가 직접 확인하고 승인합니다. 고급 Drive API(v3)와 `drive.file` 범위를 사용합니다. Drive 전체 접근 권한은 요청하지 않습니다.
5. 배포된 `/exec` URL을 `life.html`의 `DRIVE_UPLOAD_URL`에 넣고 사이트를 갱신합니다.
6. 테스트 학생 정보로 제출하여 실제 폴더 파일, PDF 1페이지, 파일명, 재시도 중복 방지, 실패 알림을 확인합니다. 다른 폴더로 옮길 경우에도 폴더 접근과 실제 저장을 다시 확인합니다.

## 학생 정보 및 개인정보

- 학년 1~3, 학과·반 6개, 번호 1~40, 이름 2~30자를 확인하고 본인 확인 체크 후 시작합니다. 이것은 입력 형식 확인이며 명렬 대조 인증은 아닙니다.
- 시험 비밀번호는 사용자가 지정한 값의 SHA-256으로 비교합니다. 클라이언트 검사는 편의 장치이며 서버에서도 다시 확인합니다. 학교 계정 본인 인증을 대신하지 않습니다.
- 비밀번호 원문은 HTML, URL, localStorage, 제출 파일에 기록하지 않습니다. 현재 화면 메모리에만 보관하고 새로고침 시 다시 입력합니다.
- 파일명: `1학년 스마트용접과 1반 3번 홍길동.pdf`.
- PDF는 1페이지 시각 요약과 `FullAnswers.txt` 첨부 원문을 포함합니다. 긴 답안은 요약 화면에서 줄임표로 표시하고 원문은 첨부에 보존합니다.
- 현재 제출 폴더는 링크가 있는 모든 사용자에게 편집 권한이 있습니다. 학생 답안을 받기 전에 폴더 소유자가 공유 범위를 검토해야 합니다. 코드에서 공유 권한을 바꾸지는 않습니다.

## 전송 동작

- 학생이 제출 버튼을 누르면 PDF를 만들고 HTTPS POST로 보냅니다.
- 서버는 비밀번호, 학생 정보, 파일명, PDF 매직 바이트, 5MB 제한을 확인합니다.
- 지정 폴더에 파일을 만든 뒤 파일 ID와 이름을 응답할 때만 저장 완료를 표시합니다.
- 응답은 Google HtmlService의 postMessage로 수업 사이트 원점에만 전달합니다. 수신 측은 Google 원점과 160비트 일회용 토큰을 확인합니다.
- 동일 학생·동일 PDF 재제출은 저장된 파일을 재사용합니다. 내용이 바뀌면 같은 파일명의 새 제출본을 보존합니다.
- 동시 저장은 ScriptLock으로 직렬화합니다. 통신이 끊기면 성공으로 표시하지 않습니다.
- 브라우저 다운로드와 전체 답안 글 저장은 Google 연결 장애에도 사용할 수 있습니다.

## 교사용 반별 제출 현황

- 배포 URL 뒤에 `?view=teacher`를 붙이면 교사용 화면입니다. 수업 첫 화면의 ‘교사용 제출 현황’ 버튼으로 연결합니다.
- Apps Script에 HTML 파일 `Review`를 만들고 `Review.html`을 넣습니다. `Code.gs`와 manifest를 함께 적용합니다.
- 명렬은 비공개 Apps Script 프로젝트에만 `const PRIVATE_ROSTER = [...]` 형태로 보관합니다. SETTINGS.classes 순서대로 반별 이름 배열 6개를 넣고, 각 배열 인덱스 0은 1번입니다. 결번·전출·자퇴 자리는 null로 두어 번호가 밀리지 않게 합니다. 실제 명렬은 공개 저장소에 올리지 않습니다.
- `userinfo.email`은 접속한 계정과 배포 소유자 계정이 같은지 확인하는 데 사용합니다. 계정 이메일을 확인할 수 없거나 다른 계정이면 모든 교사용 조회·별칭 등록을 거부합니다. 학생용 시험 비밀번호로 교사용 화면을 열 수 없습니다.
- 반별 제출·미제출, 이름 확인 필요, 번호/이름 검색, PDF 미리보기, 재제출 이력을 제공합니다. 새 제출은 ‘새로고침’으로 불러옵니다.
- 학년·학과/반·번호로 연결합니다. 명렬 이름과 제출 이름이 다르면 표시하고, 교사가 동일 학생임을 확인한 뒤 해당 번호의 별칭으로 등록합니다. 파일명이나 원본 PDF는 변경하지 않습니다.
- 형식이 다르거나 명렬에 없는 번호의 파일은 별도 목록으로 표시합니다. 이름만 보고 자동으로 다른 학생에게 배정하지 않습니다.
- `drive.file` 범위에서 앱이 접근할 수 있는 지정 폴더 PDF만 조회합니다. 다른 경로로 수동 업로드한 파일은 앱 권한에 따라 보이지 않을 수 있습니다.
- 교사용 화면의 접근 제한과 기존 Drive 폴더 공유 권한은 별개입니다. 이 기능은 폴더 공유 권한을 변경하지 않습니다.
