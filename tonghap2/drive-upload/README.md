# 생애주기 PDF 제출 연결

학생 화면과 한 페이지 PDF 생성은 `tonghap2/life.html`에 있습니다. 이 폴더는 지정한 Google Drive 폴더로 PDF를 받기 위한 서버 코드입니다.

## 연결 상태

아직 Google 계정에서 배포하지 않았습니다. `life.html`의 `DRIVE_UPLOAD_URL`은 빈 값이며, 학생에게 제출 성공을 표시하거나 기존 Google Form으로 몰래 대체하지 않습니다. PDF 다운로드는 사용할 수 있습니다.

## 교사 계정에서 한 번 연결

1. 지정한 폴더 소유자 계정으로 Google Apps Script 프로젝트를 만듭니다.
2. `Code.gs` 내용을 넣고, 프로젝트 설정에서 manifest 표시 후 `appsscript.json`을 적용합니다.
3. 새 배포 → 웹 앱. 실행 사용자: 나, 액세스: 모든 사용자. 학교 계정 정책에 따라 익명 웹 앱이 허용되지 않으면 학교 관리자 확인이 필요합니다.
4. Google이 요구하는 Drive 권한을 교사가 직접 확인하고 승인합니다. 서버는 지정한 한 폴더만 사용하지만 DriveApp의 OAuth 권한은 Drive 전체 범위입니다.
5. 배포된 `/exec` URL을 `life.html`의 `DRIVE_UPLOAD_URL`에 넣고 사이트를 갱신합니다.
6. 테스트 학생 정보로 제출하여 실제 폴더 파일, PDF 1페이지, 파일명, 재시도 중복 방지, 실패 알림을 확인합니다. 그 후 이 문서의 연결 상태를 갱신합니다.

## 학생 정보 및 개인정보

- 학년 1~3, 학과·반 6개, 번호 1~40, 이름 2~30자를 확인하고 본인 확인 체크 후 시작합니다. 이것은 입력 형식 확인이며 명렬 대조 인증은 아닙니다.
- 시험 비밀번호는 사용자가 지정한 값의 SHA-256으로 비교합니다. 클라이언트 검사는 편의 장치이며 서버에서도 다시 확인합니다. 학교 계정 본인 인증을 대신하지 않습니다.
- 비밀번호 원문은 HTML, URL, localStorage, 제출 파일에 기록하지 않습니다. 현재 화면 메모리에만 보관하고 새로고침 시 다시 입력합니다.
- 파일명: `1학년 스마트용접과 1반 3번 홍길동.pdf`.
- PDF는 1페이지 시각 요약과 `FullAnswers.txt` 첨부 원문을 포함합니다. 긴 답안은 요약 화면에서 줄임표로 표시하고 원문은 첨부에 보존합니다.
- 현재 제출 폴더는 링크가 있는 모든 사용자에게 편집 권한이 있습니다. 학생 답안을 받기 전에 폴더 소유자가 공유 범위를 검토해야 합니다. 코드에서 공유 권한을 바꾸지는 않습니다.

## 전송 동작

- 학생이 제출 버튼을 누르면 PDF를 만들고 HTTPS POST로 보냅니다.
- 서버는 비밀번호, 학생 정보, 파일명, PDF 매직 바이트, 5MB 제한을 확인합니다.
- 지정 폴더에 파일을 만든 뒤 파일 ID와 이름을 응답할 때만 저장 완료를 표시합니다.
- 응답은 Google HtmlService의 postMessage로 수업 사이트 원점에만 전달합니다. 수신 측은 Google 원점과 160비트 일회용 토큰을 확인합니다.
- 동일 학생·동일 PDF 재제출은 저장된 파일을 재사용합니다. 내용이 바뀌면 같은 파일명의 새 제출본을 보존합니다.
- 동시 저장은 ScriptLock으로 직렬화합니다. 통신이 끊기면 성공으로 표시하지 않습니다.
- 브라우저 다운로드와 전체 답안 글 저장은 Google 연결 장애에도 사용할 수 있습니다.
