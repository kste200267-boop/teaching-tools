# 생애주기 수업 관리

수업 화면은 `tonghap2/life.html`, 교사용 화면은 `Review.html`입니다.

## 교사 사용 순서

1. 수업 첫 화면에서 **교사용 관리·통계**를 엽니다.
2. 전체 현황에서 학급별 제출률과 미제출 인원을 확인합니다.
3. 반과 학생을 선택하여 결과 PDF와 재제출 이력을 확인합니다.
4. 이름이 다르면 학년·반·번호와 본인을 확인한 뒤 사용 이름을 등록합니다.
5. 검토 상태와 교사 메모를 저장합니다. 새 제출본은 다시 검토합니다.
6. 전체·선택 반·미제출 명단을 CSV로 저장할 수 있습니다.

테스트·잘못된 제출은 파일을 보존한 채 통계에서 제외하거나 복원할 수 있습니다. 제출률은 성적이나 성취도를 뜻하지 않습니다. 작성 중 진행률은 집계하지 않습니다.

## 소스 구성

공개 소스에는 실제 명렬과 서버 설정값을 넣지 않습니다. 서버 설정과 명렬은 비공개 프로젝트에서 관리합니다. 이 소스에서 사용하는 설정 키는 `SUBMISSION_FOLDER_ID`, `SUBMISSION_PASSWORD_HASH`입니다. 실제 배포 설정은 별도로 유지합니다.
